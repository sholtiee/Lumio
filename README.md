# Lumio

Бесплатный нативный менеджер дисплеев для macOS — альтернатива BetterDisplay.

Главное — **чёткий текст на обычных мониторах**. macOS не включает HiDPI для 1440p и 1080p мониторов, поэтому интерфейс рисуется в 1× и текст выглядит мыльным. Lumio создаёт виртуальный HiDPI-дисплей (например, 5120×2880 для 2560×1440), и монитор показывает его как повтор экрана. Рабочий стол рисуется в 2×, после чего WindowServer уменьшает картинку до родного разрешения матрицы — как на Retina.

## Возможности

- **Чёткий текст (HiDPI)** для любого внешнего монитора, в один клик. Набор разрешений: от «крупнее» до «больше места», плюс 1:1.
- **Профили**: выбор запоминается для каждого монитора и восстанавливается при подключении, после сна и при перезапуске.
- **Яркость и громкость** внешних мониторов через DDC/CI (Apple Silicon). Если монитор не поддерживает DDC, работает программное затемнение. Встроенный дисплей тоже регулируется.
- **Медиаклавиши** яркости и громкости управляют тем дисплеем, на котором курсор, с индикатором в стиле macOS.
- **Горячие клавиши**:
  - `⌃⌥⌘→` / `⌃⌥⌘←` — перенести окно на соседний дисплей с сохранением положения;
  - перенести курсор на другой дисплей;
  - включить/выключить чёткий текст;
  - «крупнее» / «больше места»;
  - яркость на всех дисплеях.
- Разрешение, частота обновления, основной дисплей, повтор экрана.
- **Диагностика**: почему текст мыльный, какое разрешение у сигнала, во сколько раз идёт отрисовка, плотность пикселей, поддержка DDC.
- Интерфейс в стиле Control Center и System Settings. Есть тёмная тема, русский и английский языки.

## Сборка

Нужны Xcode 16+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```bash
make run        # собрать Debug и запустить
make test       # юнит-тесты LumioKit
make release    # Release-сборка → build/Build/Products/Release/Lumio.app
make snapshots  # отрисовать панель и настройки в PNG (light/dark) для ревью UI
make strings    # пересобрать Localizable.xcstrings из ключей и scripts/ru.json
```

Подпись настроена на команду в `project.yml` (`DEVELOPMENT_TEAM`). Для другого аккаунта поменяйте её там.

## Разрешения

- **Универсальный доступ** — для медиаклавиш и переноса окон. Без него остальное работает.
- Песочницы нет: Lumio использует приватные API (`CGVirtualDisplay`, `IOAVService`), поэтому в App Store его не выложить.

## Устройство

```
LumioKit/      чистая логика без системных вызовов, покрыта тестами:
               каталог HiDPI-режимов, геометрия окон, профили, DDC-пакеты
Lumio/Private  объявления приватных API — единственное место, которое
               может сломаться при обновлении macOS
Lumio/Core     Sharp-движок, дисплеи и режимы, DDC/яркость, хоткеи, медиаклавиши
Lumio/UI       панель в меню, настройки, HUD
```

## Известные ограничения

- В режиме чёткого текста на этом мониторе не работают HDR и VRR (так же, как в BetterDisplay).
- Lumio должен быть запущен, пока включён чёткий текст. При выходе мониторы аккуратно возвращаются в обычный режим.
